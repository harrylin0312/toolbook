# 多游標效果：接手指引

## 讀取與操作順序

1. 讀 README、docs/SPEC、docs/INTEGRATION、docs/ACCEPTANCE 與預設設定。
2. 先跑 examples/index.html；需要比對原站時，讀 reference/daily-brief 的 index、style、animation、motion。
3. 複製 src 到目標網站，保留 motion.js 的加減速與 builder.js 的狀態流程；先以 data-build 標記文字元素。
4. 配合目標網站實際內容和尺寸配置元素，不複製原站新聞作為新網站的真實內容。
5. 使用測試與真人可見瀏覽器分別驗證；如果工具缺少瀏覽器控制，就明確留下此限制。

## 這些是目前使用者已調好的行為

- 每個元素工作 1500ms；出動至少相隔 100ms，不可在同一幀追補一批出動。
- 動作使用 quadratic ease-in-out：速度大致線性增加、再線性下降，並有連續追蹤與每幀位移上限。
- 單次拖框到最終尺寸；直接從空白輸入新文字。
- 不加對齊線、不先反白文字、不做第二次縮放。
- 不加游標姓名；做完後回右側，稍微重疊、安靜休息，不消失、不瞬移。
- 滾動只觸發一次；不控制動畫進度，不倒帶。
- 只在目前可見視窗內工作；持續滑動可銜接其他區域。

除非使用者明確修改需求，以上內容應保持。編輯文字時只處理動畫副本，不能改動真實內容。相同內容的資料刷新必須保留既有 DOM，避免重建導致閃爍。

`reference/` 是版本依據。最初影片與最終動畫不同；不能因影片中有對齊線或選字動作，就把使用者後來移除的行為加回去。
