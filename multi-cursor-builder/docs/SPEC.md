## 工作與排程

- 全部游標共用一個 requestAnimationFrame 迴圈，預設保留 12 個實體游標。
- 同時工作的上限：寬度 `<600px` 為 7；`600–999px` 為 10；`>=1000px` 為 12。未工作的游標在旁邊休息。
- 按元素畫面上方位置排序，第一個立即出動，後續每次出動至少相隔 **100ms**。
- 間隔以真實幀時間判斷；60Hz 顯示器可能約 100–117ms。長幀之後不能一次追補多個出動。
- 每份工作 **1500ms**，包含出發、建立／複製、移到輸入位置、打字及收尾；回休息區另約 440ms。
- 只處理可見元素。元素離開畫面時完成原內容並釋放工作者，讓下一個可見任務接續。
- 原內容不被更改；隱藏僅為視覺效果，空間持續保留。

## 動作階段

`approach = clamp(130 + travelDistance / 5, 240, 450)` 毫秒，`a = approach / 1500`，`r = 1-a`。

| 時間範圍（工作進度） | 新建元素 | 複製元素 |
| --- | --- | --- |
| 0 → a | 從游標目前位置到元素左上 | 從目前位置到來源中心 |
| a → a + 0.06r | 開始拖框 | 顯示短暫複製提示 |
| a → a + 0.42r | 十字游標，一次拖到最終右下角 | 0.06r 後切抓取手勢，把來源框拖至目標 |
| a + 0.42r → a + 0.55r | 平滑移至文字起點 | 同左 |
| a + 0.55r → a + 0.96r | I-beam，直接由空白輸入 | 同左；不先顯示舊文字，也不反白 |
| 最後 0.04r | 完成真實內容顯示，收起選取框 | 同左 |

複製重用的是同類元素的框幾何；新框文字保持空白直到輸入階段。打字途中顯示真實內容字串的前綴。最後恢復原始富文字結構，不能改動真實 DOM 的文字或來源事實。

## 移動曲線

- 前半段 `ease(t)=2t²`；後半段 `ease(t)=1−(−2t+2)²/2`。因此理想路徑速度先線性增加、再線性下降。
- 另有 critically damped follower，omega 95；每次 dt 夾在 0.001–0.045 秒。
- 位移上限 9000px/s；游標在各工作之間保留位置與速度，不直接跳到下個起點。
- 移動路徑可有很小的弧度，避免把加速度解釋成全程等速。
- 高速移動可有 3 個低透明度殘影，靜止後清除。

## 休息隊形

- 不命名、不顯示角色標籤。
- 預設第 i 個游標：`x = viewportWidth − 28 − (i % 3) × 4`。
- `gap = min(14, (viewportHeight − 72)/(poolSize−1))`，y 在視窗垂直中央對稱排列。
- 12 個游標的中心縱向跨度約 154px，圖示稍微重疊；靜止後透明度約 0.48。
- 任務完成後平滑歸位。新任務若先到，從當下位置繼續出發。
- 完成工作且歸位後停止 RAF，不靠無限循環維持靜止。

## 響應式與可用性

每幀重測元素與視窗交集；框限制在左右各 9px、上下各 9px 的視窗內。游標也在視窗內夾限。prefers-reduced-motion 直接呈現完整內容；鍵盤 focus 立即揭露對應內容；動畫層不攔截滑鼠與觸控。

可選的原生 dialog 在開啟時暫停動畫層。通用版只觀察初始化時已存在、由 dialogSelector 選到的一個 dialog；複雜 SPA 需自行接整合生命週期。
