# 驗收

## 計算／DOM 測試

- 每格 duration 為 1500ms，所有出動時間相隔至少 100ms。
- 加速與減速前後半段的速度差接近線性；精確抵達目標，沒有跨任務瞬移。
- 首幀只出動一個，其他游標留在原位；一段時間後多人可同時工作。
- 原文不被更改；打字前的副本是空白，打字時只顯示目標文字的前綴。
- 沒有對齊線、文字反白或第二次縮放。
- 做完後所有游標仍在畫面上；右側稍微重疊、不命名，歸位後停止更新。
- 新資料相同時保持 DOM；掃描不把動畫副本當成新目標。
- 視窗縮放、快速捲動、dialog、鍵盤 focus 與 reduced motion 有對應行為。

## 真正瀏覽器檢查

至少檢查 1440×900、768×1024、390×844 與手機橫向。逐區停止滑動觀察一遍，再持續快滑、回滑、縮放及開啟詳細內容。錄製或擷取可見的出動、拖框、打字與休息片段，並標註測試裝置。

## 本次交接的證據與限制

reference 快照來源版本的 motion 與 DOM 邏輯測試已通過。此套件另有通用版 DOM 測試；幾何由測試模擬，不等於實際排版。當前執行環境沒有可用的瀏覽器控制工具，不能宣稱已完成新示範頁的視覺或錄影驗收。

原始影片是使用者提供的靈感資料，不可當作我們實作的驗收錄影。不同版面只要求一致的行為與節奏，不能聲稱像素完全相同。
