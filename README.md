# 工具書

集中保存可重用的程式、設定、範例、資料與規格，讓未來的 AI 或開發者能讀取後接手，不必重新猜測設計。

## 工具目錄

| 資料夾 | 用途 | 版本 |
| --- | --- | --- |
| [multi-cursor-builder](multi-cursor-builder/README.md) | 多游標分工建立網頁元素；1.5 秒動畫、0.1 秒依序出動、右側重疊休息 | 1.0.0 |

新增工具時，放在新的獨立資料夾，並在這張表新增一列。各工具自行保存原始碼、設定、示範與文件，不要把不同工具的內容混在一起。

## 給下一個 AI

先讀 [AGENTS.md](AGENTS.md)，再讀目標工具的 README、AGENTS、規格與驗收文件。需要忠實重現時，使用工具內的參考原始碼與版本資訊，不要只憑文字描述重新設計。

可直接使用的任務描述：

> 請讀取這個儲存庫的 AGENTS.md，以及 multi-cursor-builder 的 README、AGENTS.md、docs/SPEC.md 和 docs/INTEGRATION.md，依照 1.0.0 的行為把多游標建立效果套到我的網站。沿用原始碼、只調整目標元素與必要樣式，完成後依 docs/ACCEPTANCE.md 驗收。

此儲存庫預設以私人形式建立；使用私人儲存庫時，接手者需要已授權的 GitHub 連線或本機檔案存取。不要直接把它當成公開 CDN。
